转折but · however · yet · whereas · in contrast答案句,F 坑
因果because · so · therefore · lead to · due to判断考点,方向别反
并列and · also · as well as · another多选,数几个
举例such as · like · for example · (括号)填空,括号必看
强调in fact · actually · especially · onlyHeading · 程度考点

否定prevent · lack · fail · without · rarely藏着的 not,判断

不能死等一个单词。改写 8 种:词性变 · 同义词 · 上位词(blue→colour) · 解释 · 双重否定 · 代词 · 颠倒(floor of the ocean) · 主被动

定位词 · 只圈改不动的

数字 年份人名 地名大写 专有名词怪词 术语朴素具体词(同义词少)importantdevelopment文章主题词
三原则:找得快 · 全文唯一 · 组合两三个。红的抽象词必被改写,圈了等于没圈。四类全无 = 题干已抽象化,放弃扫描,走顺序推进
题干给「类」,原文给「例」:题干 human behaviour,原文 cutting down forests。读文章不问这个词在哪,问这句是不是那一类

8 种题型

判断 T/F/NG · Y/N/NG顺序占 30%,T 41% > F 32% > NG 26%
做法 一次读两题,记住两题的词再回文 · 读题慢,题干长的读两遍 · 判之前在题前加「是否」 · 读到下一题的位置了上一题还没出现 = NG
命题 T1 单句改写 · T2 相邻句归纳 · T3 跨段归纳 ‖ F1 反义词(several↔only one) · F2 关系驳斥(before↔after) ‖ NG1 题干前/后的信息原文没有 · NG2 题干中间的关系(more than)原文没有
考点 时间(before/after) · 程度(all/only/rarely/most) · 比较级 最高级 · 数字 · 因果方向 · 主体是谁 · 作者态度
首题少 NG,末题少 F。内容词对上只算定位,对错只看逻辑词:相反 = F,原文没这个维度 = NG
你错过breed = 繁殖 不是养育 → 用了 NG 其实是 F你错过attempts 读成「证据」,把题读快了 → 审题你错过pests 攻击的是 rice,毁林的是农民 → 看清作用受体你错过In the future 预测句 → 原文 predict 是态度不是事实,先问「是否」
填空 · Summary · 句子完成顺序(偶有 1-2 题倒)
4 步 ① 先定 summary 在原文哪一块(小标题) ② 看空前后,判词性 n/adj/v ③ 回原文锁定答案 ④ 填完整段读一遍通不通
规矩 看清字数 NO MORE THAN TWO · 答案多是难词/生词 · 可能要变词性 · 空格旁边的词 = 原文同义词
你错过numbers 写成 number → 完!全!复!制!做完检查每个空你错过visual 填成 images → 先判词性,这里要 adj你错过coffee 填成 twig → 两个名词并列选更具体那个,括号里的一定看你错过award 填成 assistance → 搞清主体:assistance 是 locals 要的,award 是 authorities 要的;题干有 a 就画出来你错过words 填成 tones → 题干已经出现的词不会是答案;which 后置修饰 = 题干把名词放前面你错过biodiversity 填成 nutrients → 原文 not for nutrients,否定词决定不是它
Heading 段落标题乱序 · 随读随收
做法 ① 先划掉例子用过的 heading ② 选过的立刻划掉 ③ 拿不准的放最后,范围缩小再排除 ④ 先做这段的细节题,最后选 heading
来源 首句 · 设问句 · 举例前的观点句 · 转折句 · 强调句 · 定义句 · 下一段首句
你错过publicity = 宣传 不是公众,一直在找「公众」你错过commercial orders 看不懂 → 原文 received 5,390 deposits,抽象词找具体数字
段落信息 Which paragraph contains乱序 · 随读随收
做法 读所有题,圈词,短暂记住 → 从首段读起,先做其他题型在这段的题,最后收这段的信息题 → 某段出现题干词的同义词一次就能定 · NB = 有段落会用两次
题干是抽象的 examples of = 原文一串名词 · reference to disadvantages = 原文 lost / problem · a certain era = 原文具体年代 · proportion = 原文数字 或 half
段标签 每读完一段写 3 个字(A 各说各话 · B 瘦素饥饿 · C 小改没用 · D 孕期 · E 饮食对比 · F 病毒鸡 · G 基因疫苗),信息题靠标签配,不回文
你错过gene + virus 选了 F → F 只有 virus,G 才有 gene,两处都对上才落笔你错过facilities 认成 steel and concrete → 设施是 hotels / restaurants 那段,材料不是设施你错过have already been lost 没看时态 → 原文 have disappeared,时态也能排段你错过没找到 → 读每段时先猜「这段能出什么题」,做完细节题再扫一眼每段
单选 A B C D顺序
本质 正确项 + 题干 = 一句 TRUE;干扰项 = F 或 NG。正确项两种:单句改写 · 上下文归纳 · 问 What is the writer doing = 看段落功能(support / propose / reject / describe)
你错过选了 reading skills → 原文只说像字幕,没说 reading 辅助,是你推断的。选直观明显的,不推断你错过Noise + distance 两个方面 → 越细的题越要把每个方面数清,选「aspects」
多选 五选二 / 七选三半顺序 · 集中 1-2 段
做法 答案基本在一到两段里 · 差不多的先选上,没找到就选最像的 · 并列词 and / also 数个数
你错过amenities 不认识 → 设施。E 段 hotels retail… = community life,F 段 panels turbines = renewable 设备
人名 / 观点匹配乱序 · 人名是路标
做法 人名大写改不了,先全圈,读到谁就看谁说了什么 · 一人可对多题(NB) · 题干是观点的「类」,原文是那人的原话
引号归属 says X 管的是它前面到上一个 says 为止的句子。一段两个人名,先画 [ … ] says X 再配
你错过Barrett ↔ Friedman 互换 → C 段两个人,goal shouldn't be thin but healthy 后面跟的是 says Friedman你错过Bombay 填成 chickens 的空 → 题干已有的词不是答案;conducted on 后面是实验对象不是地点
句子配对 Complete each sentence A-E顺序
做法 前半句定位,后半句在选项里找同义 · 放中间的题答案也在中间,别上来就在开头找 · 相邻两题不会离远,可能就是下一句
你错过speech 被改成 voice,定位词圈了会被替换的词 → 圈 Japan / TV 这种改不动的

节奏

你的病:读着读着忘了题

一段一停 · 手指压在当前题号上 · 单位是段不是句
读完一段就抬头,看手里那两题能不能收。不是读完全文再找,也不是一题一题回头翻

福尔摩斯 · 先推理,再找

福尔摩斯不满屋子翻,他先说出答案长什么样,再去证实。每题动笔前 5 秒,先推出三件事:
推位置顺序题 → 在上一题答案句下面 · 题号在题组中间 → 答案在文章中间 · 段落信息题「examples of」→ 找 such as 那段 · 「future / predict」→ 末段 推形状空前有 a / an → 单数名词 · 空前 the parts that deal with ___ input → 形容词 · 空前 and → 和前面同类词 · 字数限制 TWO WORDS → 答案多半是 adj + n 推陷阱题干有 all / only / rarely / before → 程度或时间考点,原文必有对应词 · 题干有比较 more than → 原文没比较就 NG · 题干两个名词并列 → 要填更具体那个 推对手出题人把原文具体 → 抽象(deposits → commercial orders),把名词前置 → 后置(which),把 not 藏进 lack / prevent。看到这些就知道他在哪动了手脚
推完才找。找到后反推:这句能不能改写成题干?改不成就不是答案句,别硬凑

臭毛病 → 换成动作(100% 的钥匙)

错题表里反复出现的 10 个。毛病改不掉,动作能换掉:每个毛病对应一个手上的动作,做完才准动笔
毛病证据换成动作
读快了attempts 读成证据 · 首题慌选 NG题干用笔尖逐词点一遍,长句读两遍
不看主体assistance / award · pests 和 forest题干主语画框,原文主语画框,两框对上才算
不完整复制numbers → number填完回原文逐字母对一遍,每空打钩
不判词性visual → images空格上方写 n / adj / v 再回文
跳过括号coffee 漏掉 (which infests coffee)原文括号画圈,括号里的名词优先
靠推断reading skills 是你想的选项能在原文指出那句才选,指不出的划掉
圈错定位词speech 被换成 voice只圈 数字 人名 大写 术语,圈到 important 就擦掉
生词瞎猜breed · publicity · staging · amenities错题里的词当天进 Anki,考场上看前后缀 + 并列词猜
不问「是否」In the future · clear distinction判断题题前写「是否」二字,再判
读完忘题回去找,乱节奏一段一停,手指压题号,每段末看一眼手里两题
速度来自推理省掉的翻找,正确率来自动作省掉的侥幸。两个都要,就两样都做

开卷 6 步(每篇都一样)

1
标题 10 秒 猜是 4 种骨架里哪种,脑子里先摆好段落走向
2
扫题型块 看 instructions 不看题。标 顺序(判断 填空 单选 句子配对) 和 乱序(Heading 段落信息 人名)
3
乱序题先全圈 Heading 划掉例子;段落信息圈词记住;人名全圈
4
顺序题只看前两题 圈改不动的词,别一次看十题
5
读段 A → 停 先收顺序题,再收这段的乱序题,最后选这段 heading。手指移到下一题
6
读段 B → 停 重复。读到人名就看人名题,读到数字就看填空
老师原话:标题 → 题型 → 每题型前两题划重点 → 看 P1 → 前两题 → P2 → 3、4 → P3 → 5、6

题型组合 → 读法

判断 + 填空P1 经典 · Potato · Ancient societies · Nutrition
全顺序。两题一组往下走,判断做完填空接着从那个位置往下,不回头。17 分钟送分篇
Heading + 判断 / 多选Gilbert · Bitterness · Bird Migration · Music Language
先划例子 heading。每段:读 → 做这段的判断 → 再选 heading。多选最后在 1-2 段里扫
段落信息 + 判断 + 人名Farmers · Mars · Water Filter · Weight Loss
段落信息题先圈词记住(它是抽象的)。判断按顺序主线走,读到哪段顺手收信息题,人名出现就收人名
单选 + Y/N + Summary / 句子配对P3 经典 · Designed to Last · Communication · Musicophilia
全是顺序题,一路往下。单选当判断做:选项 + 题干 = 一句 TRUE。Y/N 只认作者自己的话。21 分钟,难题 90 秒卖掉

时间 + 止损

· 17 / 20 / 21 分钟,只在换篇时看一次表
· 一题 90 秒上限:回文两次没定位 · 超两分钟 · 剩两个选不出 → 写一个最像的,打标记,走
· 跳题后复位:呼吸一次,下一题重新圈词,不带上一题的段落假设
· 答题卡永远不留空。NG 和 F 分不清时:原文有这个维度就 F,没有就 NG

错题归因 ABC

A 没找到定位词圈错(圈了抽象词或会被替换的词) → 练锚点 + 顺序推进B 没读懂找到句子了但意思不懂 → 整句抄进长句本,查 breed / publicity / staging 这种词C 判反了读懂了但逻辑词判反(主体 · 时态 · 程度 · 否定) → 那个词抄进逻辑词清单
你的错题表里:A 占 4,B 占 7,C 占 8。C 最多 → 每题动笔前默念「主体是谁 · 时态 · 程度词 · 有没有否定」
